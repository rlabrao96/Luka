# Luka — Feature Roadmap

## Current Status (March 2026)

All core features implemented and live in production:
- OAuth login (Google + Microsoft)
- Fintoc bank connection + 90-day history import
- Email transaction capture (Gmail + Outlook webhooks)
- LLM merchant categorization with learning cache
- WhatsApp transaction alerts + category/split actions
- Dashboard with KPIs, spending trends, category breakdown
- Transaction list with personal/shared/all tabs
- Household budgeting with waterfall visualization
- Personal budget allocation (50/20/30 suggestions)
- Partner contribution transparency (privacy-safe aggregates)

## Differentiators

What makes Luka extraordinary in the Chilean market:

1. **Proactive WhatsApp insights** — AI-powered spending analysis delivered via Chile's #1 messaging platform
2. **Cashflow forecasting** — "Tendrás $X en 30 días" — no Chilean competitor does this
3. **Financial health score** — Gamified engagement with badges and streaks
4. **Couple money harmony** — Shared goals, fairness metrics, gentle nudges — "the app that helps couples talk about money without fighting"
